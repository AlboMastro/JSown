# JSown

> Fast client-side utility that transforms raw JSON payloads into clean, structured Markdown documentation.

## Why JSown?
Writing API documentation and structuring data payloads for READMEs or internal wikis is a repetitive chore. JSown was built as a lightweight tool to speed up the process, saving time and reducing friction when documenting schemas.


## Features
- **Zero Latency & Private:** Runs entirely on the client side so that data never has to touch an external server.
- **Smart Parsing:** Differentiates between arrays (converting them to structured Markdown tables) and nested objects.
- **Error Resilient:** Real-time syntax validation catches malformed JSON inputs.
